# Sohag Hasan — PHP & Laravel Developer Portfolio

A clean, modern, and fully responsive personal portfolio website built with **HTML**, **Tailwind CSS**, and **vanilla JavaScript**. It showcases my skills, experience, and contact information as a PHP & Laravel Developer.

## 🚀 Live PEN Demo 

https://app.pen.dev/s/mRnwyGAKUj2tYruKkLQk7lmCbLUSCuZibl7G8IUDS0E



## ✨ Features

- **Responsive Design** — Looks great on desktop, tablet, and mobile devices
- **Smooth Scroll Navigation** — Fixed navbar with active section highlighting
- **Mobile-Friendly Menu** — Hamburger menu for smaller screens
- **Scroll Reveal Animations** — Elements fade in smoothly as you scroll
- **Modern Glassmorphism UI** — Clean cards with subtle gradients and blur effects
- **Skills Showcase** — Visual grid of technologies I work with
- **Experience Timeline** — Professional journey section
- **Contact Section** — Direct links to email, LinkedIn, and GitHub

## 🛠️ Technologies Used

- **HTML5**
- **Tailwind CSS** (via CDN)
- **JavaScript**
- **Google Fonts** (Inter)
